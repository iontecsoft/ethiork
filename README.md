# Ethiork
## Why 

Ethiork is an open source ecosystem with the goal to help regular consumers escape digital surveillance and protect their privacy.

## What 

In order to get started with Ethiork on your own you need to understand how to install Ubuntu server and have some knowledge of command line interface. If you'd like to skip that part you can always purchase one of our preloaded boxes with or without support. It's your choice. Any donations made to this project will also directly benefit development team and allow us to move faster and stay longer independent.

## Installation

If you made this far you are confident that you can work things out on your own:
1. Install Ubuntu Server on hardware you'd like to use. There are might be limitations for supported software modules based on processor type, however all Ethiork code is platform independent and support both ARM and x86 architectures.
2. Create config file, enabling modules that you'd like.
3. Run setup script
4. Enjoy.

## Code 

All code that Ethiork consist of can be found in this repository and preloaded boxes contain additional automatic updates system that will be published when it's out of our internal beta.
